# Amazon Clone

A frontend clone of Amazon's website built using HTML and CSS.

## About the Project

This project recreates the basic layout and design of Amazon's website as a web development practice project. It helped me improve my understanding of HTML structure, CSS styling, and webpage layout.

## Features

- Amazon-inspired homepage design
- Navigation bar
- Search bar interface
- Product sections with images
- CSS-based styling and layout

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
Amazon-Clone/
├── index.html
├── style.css
├── images/
│   ├── product1.jpg
│   ├── product2.jpg
│   └── other product images
└── README.md
```

## Getting Started

### Prerequisites

A web browser and a text editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/shivamgupta6375/Amazon-Clone-.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
